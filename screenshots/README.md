## 📝 Quick Instructions

### Taking Screenshots on Mac
```
Cmd + Shift + 4  →  Select area to capture
```

### Moving Screenshots Here
```bash
cd ~/Bob/"Digital Decluttering agent"
mv ~/Desktop/Screenshot*.png screenshots/
```

### Renaming Screenshots
```bash
cd screenshots/
mv "Screenshot 2026-04-16 at 1.23.45 PM.png" dashboard-main.png
```

## 🎨 Best Practices

- ✅ Use PNG format
- ✅ High resolution (Retina quality)
- ✅ Show real data (not empty states)
- ✅ Keep under 1MB per file
- ✅ Use descriptive filenames
- ✅ No sensitive information visible

## 🔗 Markdown Syntax

To reference screenshots in README:
