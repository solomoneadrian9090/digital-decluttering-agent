# Quick Start - Digital Decluttering Agent App

Get started with the native macOS app in 3 easy steps!

## ⚡ Quick Start

### Step 1: Install Dependencies

```bash
cd ~/Bob/"Digital Decluttering agent"
npm install
pip3 install -r requirements.txt
```

### Step 2: Launch the App

```bash
./launch-app.sh
```

### Step 3: Run Your First Scan

1. Click the **"Run Scanner"** button in the app
2. Wait for the scan to complete (may take a few minutes)
3. Review the results in the dashboard
4. Use filters to find files you want to delete
5. Select files and click **"Move to Trash"**

## 🎯 That's It!

You're now ready to declutter your Mac!

## 🆘 Need Help?

### App Won't Start?

```bash
# Check Node.js version (should be 18+)
node --version

# Reinstall dependencies
rm -rf node_modules
npm install
```

### Scanner Not Working?

```bash
# Check Python version
python3 --version

# Reinstall Python dependencies
pip3 install -r requirements.txt
```
